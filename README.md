# LLM-for-Manufacturing-Quotation
calculate price by LLM

用户前端问答界面

    ↓
    
【主链路（延迟目标 200~700ms，无大模型）】
    自然语言输入 → 轻量实体抽取（材质/工艺/数量/尺寸/表面处理/精度）→ 结构化表单JSON
    
    ↓

本地计算引擎（字典/内存表查表 + 成本公式）

    ↓
    
输出报价明细 + 总报价（误差由基础库决定，目标±8%）

【旁路AI链路（异步/按需触发，不计入1s响应时限）】
当轻量解析识别到信息不足、语义模糊、看不懂行业黑话时：
才调用内置AI，反问用户补充信息、整理复杂需求、解释报价风险
